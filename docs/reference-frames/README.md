# Extracted reference frames

Numeric filenames use global time after concatenating clip_00, clip_01 and clip_02 durations (25.600 +21.333 +17.800 seconds). Native resolution1918×994. Sampled frames cover the full timeline at roughly2-second intervals. open-* adds100 ms steps across opening. adjacent-open-* contains consecutive30 fps frames at transition onset. opening-frame-measurements.csv in the parent directory contains a consecutive native-frame geometry analysis; samples are not treated as proof of unseen gestures.
